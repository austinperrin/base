# Runbook Template

[Docs](../README.md) > [Runbooks](README.md) > Runbook Template

Copy this structure for a new procedure. Replace the title, breadcrumb, prompts,
and related links with task-specific content, then register it in the runbook index.
Remove these authoring instructions from the resulting document.

## Objective and Triggers

Describe the result and the event or maintenance activity that starts the procedure.
Link to the owning standard instead of repeating its policy.

## Prerequisites and Access

List the operator's role, required permissions, tools, and input information.
Identify conditions that require stopping or asking the responsible maintainer.

## Procedure

1. Record the starting state and confirm the prerequisites.
2. Describe each action, including commands where useful and the expected result.
3. State how to handle unexpected results before continuing.

## Verification and Evidence

Define observable success criteria and where to record the outcome, unresolved
items, and supporting links. Exclude credentials and other private information.

## Recovery and Escalation

Explain how to correct reversible changes and when to stop for maintainer review.
Identify actions that cannot be undone and any required follow-up.
