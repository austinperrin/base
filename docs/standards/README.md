## External Platform Guidance

When adding or changing repository platform features, follow the provider's
current official requirements and applicable recommendations. Link the relevant
documentation from the owning standard, explain departures from recommendations,
and verify required configuration and settings. GitHub is the current default
implementation; a project may use another provider.
